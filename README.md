## 👋 Sobre mim

Sou o Apolônio,

trabalho com **segurança ofensiva**, usando Linux como ambiente de ataque, Docker para montar laboratórios isolados e Python para automatizar reconhecimento e tarefas repetitivas.

Também desenvolvo sistemas web e automações, o que me dá visão de como as aplicações funcionam por dentro e onde costumam falhar.

---

## 🎯 Foco

| Área | O que faço |
|---|---|
| 🔍 Reconhecimento | Scanning, enumeração de serviços e diretórios |
| 🧪 Laboratórios | Ambientes vulneráveis isolados em containers |
| 🐍 Automação | Scripts em Python para recon e tarefas repetitivas |
| 📝 Relatórios | Documentação clara de achados e mitigações |

| Fase | Descrição |
