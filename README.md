## 👋 Sobre mim

Sou o Apolônio, desenvolvedor com foco em **segurança ofensiva**. Meu trabalho gira em torno de entender como sistemas e redes funcionam e, a partir disso, identificar onde eles podem falhar.

Uso o Linux Fedora como ambiente principal de trabalho, aproveitando seu terminal e seu ecossistema de ferramentas para reconhecimento, análise e testes de segurança. Para praticar de forma segura, monto laboratórios isolados com Docker, onde posso executar testes sem risco para outros sistemas e reproduzir cenários vulneráveis de maneira controlada.

Em Python, desenvolvo scripts que automatizam etapas de reconhecimento e tarefas repetitivas, o que torna o processo mais rápido e organizado.

Minha experiência com desenvolvimento web e automações me dá uma visão de dentro das aplicações: como são construídas, como se comunicam e quais decisões de projeto costumam abrir brechas. Esse conhecimento complementa a análise ofensiva e ajuda a propor correções mais precisas.

Todos os testes que realizo acontecem exclusivamente em ambientes próprios ou com autorização, seguindo princípios éticos e de responsabilidade profissional.
